# 知识与报告

项目自有领域入口，统筹细分目标、自有/上游选用、证据与交接。完整流程见[SKILL](SKILL.md)，来源与输入细节按需读取，不预加载全部依赖。

- 可以从主workflow进入，或直接指定本skill；具体能力也可直接开始，均复用同一任务上下文。
- 示例：查已有性能对照经验；或生成本周工作报告。
- 输入：当前目标、已有材料、实际版本/环境与授权；输出：选用方法、结果/证据、验证范围、缺口及下一步。
- 首次目标/新错/条件变化按[共用约定](../../../docs/guides/skill-routing.md)定向查知识，已覆盖结果复用；不自动写库、升级来源或扩大运行授权。
