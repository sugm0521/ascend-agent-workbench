# 工程任务总入口

`ascend-agent-workflow` 的使用说明，面向提出任务的使用者；详细执行规则以 [SKILL.md](SKILL.md) 为准。

## 能做什么

把问题定位、模型适配、性能/精度、部署或CI目标转成可推进的任务，查证事实、澄清必要取舍并选择领域入口。

## 什么时候用

不知道该用哪个skill，或一个目标涉及多条工程路径时使用；简单问答可直接回答。

相邻入口：[ascend-task-planning](../ascend-task-planning/README.md)、[ascend-task-execution](../ascend-task-execution/README.md)。

## 怎么调用

- 使用 $ascend-agent-workflow，请帮我定位已有服务启动失败的原因，先分析，不修改业务代码。
- 使用 $ascend-agent-workflow，请先对齐吞吐优化的目标和验收条件，再给出推进方案。

## 需要提供什么

目标、已知现象及禁止操作；已有任务可直接指定任务名。

agent 会先查：已有任务、代码和环境记录，以及可用的领域skill与工具；只询问影响判断的缺项。

## 会产出什么

已确认的目标、范围、验收条件、领域路由和下一步；需要持续推进时建立或恢复任务记录。

## 操作边界

分析请求不自动升级为业务修复；不会为了简单问题强制初始化、建任务或拆分。修改、运行和发布遵循本轮具体授权。

返回[项目功能索引](../../../README.md)。提交、推送和发布统一遵循[项目规则](../../../AGENTS.md)及本轮具体授权。
