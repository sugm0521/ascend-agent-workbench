# 运行环境复现清单

遵循[项目规则](../../../AGENTS.md)。本入口只读采集并整理复现条件，不执行部署、升级或推理，也不保证目标环境已具备可复现证据。

## 定位目标与证据模式

- 从用户指定目标或本会话实际任务绑定确认节点、容器/运行入口、解释器、代码与服务；不按cwd猜远程任务，不自动选择其他会话的容器。缺少影响采集的目标时先查本会话记录，仍未明确才问。
- 区分启动前选用环境、运行中实际加载环境、历史记录整理及本地模拟。输出采集时间、证据时间和覆盖目标；历史内容不能写成当前实测。
- 用户禁止真机或要求模拟时，只使用本地文件/已保存证据进行文本走查；不调用远程工具、SSH、Docker或NPU操作。模拟值明确标注，不用它填补真实证据缺口。

## 采集与输出

按[清单字段与来源](references/snapshot-fields.md)读取本次需要的信息。复用仍适用的原始证据和现有运行工具，逐目标核对共同字段与角色差异，不默认扫全部包、全部历史PR或所有环境。

- 使用服务实际解释器的包metadata、实际Git根/完整SHA/dirty、镜像/构建来源和任务PR记录；模块安装路径与进程加载来源分别记录。
- 只读已有进程信息/库映射，不为快照初始化NPU、导入可能有副作用的原生模块或发送推理请求。仅输出快照的请求不自动运行native probe；安装字节核对按需要引用已有artifact manifest。
- 每次实际启动/重启前刷新版本、代码及环境选择，输出简短清单，保存该attempt的详细记录并关联最终命令、环境、日志；单纯查看状态不创建启动attempt。
- 本轮替换组件或来源歧义影响判断时，启动后由部署执行方读取实际进程证据补入同一记录；本skill不自行重启或部署。
- 未知、冲突、未验证明确标记；同一版本字符串不能证明相同代码或包，包已安装不能证明存量worker生效。

输出简短摘要和可读复现文档，按实际需要保存小型结构化清单。产物落当前任务目录或项目忽略目录，不写凭据，单次上传不超过1MB。大型patch/模型索引/清单留原位置，只给证据引用；不为每次启动全量hash权重或安装树。

## 完成条件

目标、阶段、字段来源、修改项、未知项与证据入口齐全，足以判断已记录条件和缺口。清单完整度、环境兼容、实际功能与性能分别判定。没有当前真实请求证据，不称服务成功；关键版本或patch不可恢复时，不称可精确复现。

与其他入口分工：部署使用[部署说明](../ascend-agent-workflow/references/service-deployment.md)，升级由[dependencies](../ascend-workbench-dependencies/SKILL.md)负责，实际兼容/产物工具见[运行工具说明](../../../docs/runtime-tools.md)。正常快照不启动这些变更或实验流程。
