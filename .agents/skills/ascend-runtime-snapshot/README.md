# 环境复现记录

`ascend-runtime-snapshot` 的使用说明，面向提出任务的使用者；详细执行规则以 [SKILL.md](SKILL.md) 为准。

## 能做什么

只读整理指定容器的原始镜像、代码、逐笔叠加PR、替换依赖与启动条件，维护最小复现记录和本机总表。

## 什么时候用

部署前核对环境、交接已有容器或整理历史复现条件时使用；单项版本问答无需全量采集。

相邻入口：[ascend-workbench-init](../ascend-workbench-init/README.md)、[ascend-container-ssh](../ascend-container-ssh/README.md)。

## 怎么调用

- 使用 $ascend-runtime-snapshot，为指定已有容器整理最小复现记录，只读采集，不部署或运行推理。
- 使用 $ascend-runtime-snapshot，核对这份历史环境记录哪些有当前证据、哪些仍未知，不启动服务。

## 需要提供什么

本会话实际目标容器/运行入口，或明确的历史记录；说明要记录选用环境还是实际加载环境。

agent 会先查：镜像身份、代码SHA、PR与依赖替换证据、已有进程和库映射；不按当前目录猜远程归属。

## 会产出什么

更新后的本机容器表入口、必要复现摘要、采集时间、覆盖范围与未知项。

## 操作边界

业务环境采集只读，整理可更新本机记录；不部署、升级、初始化NPU、主动导入原生模块或发送推理请求，不展示口令。
