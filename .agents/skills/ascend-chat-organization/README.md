# 会话命名与整理

统一 Codex 会话标题，让开发、部署、学习和分析工作可以按对象和目标检索。

- 当前会话：新任务目标明确后自动调整，目标明显变化时更新；普通追问不改名，保留用户指定标题。
- 批量整理：例如“统一当前项目所有会话名字”，按实际内容改名并核对；清单不完整时明确覆盖范围。
- 输入：当前任务目标，或用户指定的项目/会话范围；输出：核对后的标题及必要的改名前后清单、失败或歧义。
- 命名格式：`[类型] 对象 | 具体目标`，例如 `[分析] KV Pool | 定位对象读取失败`。
- 只改标题不自动移动或归档，不改变 MindIE 运行身份；缺会话工具时报告缺口。

执行规则见 [SKILL.md](SKILL.md)。项目级 hook 的安装、信任与验证见 [Codex 接入说明](references/codex-integration.md)，脚本和模板随本 skill 维护；实际本机配置不提交。
