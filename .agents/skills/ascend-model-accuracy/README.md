# 模型精度与输出质量

`ascend-model-accuracy` 的使用说明，面向提出任务的使用者；详细执行规则以 [SKILL.md](SKILL.md) 为准。

## 能做什么

复现和定位乱码、复读、空输出、参考结果不一致或评测下降；在明确修复授权内实施候选并组织目标场景回归。

## 什么时候用

模型输出质量或精度异常使用；普通启动报错、纯性能问题及已隔离的算子误差走各自入口。

相邻入口：[ascend-performance-benchmark](../ascend-performance-benchmark/README.md)、[ascend-agent-workflow](../ascend-agent-workflow/README.md)。

## 怎么调用

- 使用 $ascend-model-accuracy，定位这组请求为什么出现复读，对照原始输入和评测配置，先不改代码。
- 使用 $ascend-model-accuracy，修复已确认的输出异常，并复验原始bad case和约定的回归场景。

## 需要提供什么

异常样本/请求、服务或模型版本、正常参考、触发条件和验收标准；说明允许修改与运行的范围。

agent 会先查：原始响应、token/模板/采样和评分条件、已有精度记录；先区分输入解析与模型问题。

## 会产出什么

bad case与对照证据、致因判断和限制；授权修复后提供改动、因果证据及回归结果。

## 操作边界

定位不包含业务修复或服务重启；不能以HTTP成功或一次现象消失宣称精度通过。内部逐题结果、日志与张量按规则留远端，不自动下载全文或发布。
