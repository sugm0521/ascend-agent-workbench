# 外部组件集成

此目录维护工作台对外部工具的接入和定制。每个组件独立放在 `integrations/<组件名>/`，后续看板、编辑器插件或其他外部工具按实际需要增加，不把其他组件塞进 npu-top，也不预建空目录。

| 维护内容 | 位置与边界 |
|---|---|
| 接入说明、可重放补丁、必要附加源码、安装/构建脚本、组件测试 | 当前组件目录；普通安装不得依赖本机任务材料或手改外部源码 |
| 官方来源、精确版本与制品 SHA256 | [upstream](../upstream/) 中的权威锁；组件 manifest 引用，不重复维护另一套 pin |
| 组件定制版本、补丁/静态资源/启动入口 SHA256 | 当前组件 manifest；版本升级同时重建、核对差异与验证 |
| 确需复用的跨组件代码与整体测试 | 根 `scripts/`、`tests/`；组件专用实现和测试留组件内 |
| 操作方法与 agent 入口 | 原 `.agents/skills/`；引用组件说明，不另建 skill 维护副本 |
| 环境、缓存、日志、数据库、凭据、真实服务器清单 | 忽略提交的 `.workbench-local/` 或使用者显式指定的本机目录；不能纳入组件源码包 |
| 外部维护源 | `deps/` 继续只读；补丁在独立候选副本重放，不直接改维护源 |

当前组件：[npu-top](npu-top/README.md)。

新组件按实际需要提供说明、manifest、补丁/源码、安装和测试；没有补丁或资源时不创建占位目录。一个组件自行管理自己的安装产物，不接管原工具的身份、远程执行、设备租约或资源调度。默认独立安装、先核对已有端口和状态，再按明确授权切换。

换路径采用从版本管理材料重新安装环境，不直接搬运虚拟环境。在线安装从固定地址取得并校验官方制品；受限网络可先准备可核验的离线包。验收分别报告干净安装、换路径、本机服务运行和真实第二台机器的覆盖范围。
